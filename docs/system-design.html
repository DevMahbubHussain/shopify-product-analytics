PlanetScale Access Path Design Insight

Live merchant dashboards query exclusively from product_daily_metrics using the composite B-Tree index (shop_id, metric_date). Because metrics are precomputed during ingestion, range queries execute in <10ms and never perform full table scans over millions of historical order_line_items.

6. Performance & Scalability Safeguards

Key engineering patterns and architectural boundaries implemented to guarantee production reliability.

1. Sub-50ms Dashboard Read SLA

Live dashboard requests never touch raw order line items. Precomputed aggregates stored in product_daily_metrics are queried directly via composite indexes, guaranteeing sub-50ms responses regardless of total catalogue size.

2. Zero Access Token Leakage

Shopify OAuth credentials reside strictly in React Router server session storage. Browser frontend and the Laravel backend never receive or store raw Shopify access tokens.

3. Concurrency & Deadlock Guard

All multi-row upserts use DB::transaction(fn() => ..., 5) for automatic PostgreSQL deadlock recovery. Worker execution is bounded by Redis atomic locks using WithoutOverlapping.
